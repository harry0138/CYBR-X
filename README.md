# TECHFEST Cursor Experience

A responsive 3D-inspired Techfest landing page where the scene reacts to cursor movement. Built with HTML, CSS and vanilla JavaScript; the central cube uses CSS 3D transforms, so no framework or build step is required.

## Run
Open `index.html` in a modern browser.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.

## Customize
Edit the event year, text, colors and official link in `index.html` / `style.css`.

Reference: https://techfest.org/

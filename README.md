# CYBR-X — 2D Cyborg Landing Page

A responsive futuristic landing page built with plain HTML, CSS and JavaScript.

## Design
- 100% 2D — no 3D models, WebGL or Three.js
- Cyberpunk HUD aesthetic
- Neon cyan/violet accents
- Scanlines + grid
- Boot sequence
- Animated system statistics
- Responsive navigation
- Interactive augmentation cards
- CSS-only cyborg system visualization

## Run
Open `index.html` in a browser.

## GitHub Pages
Create a repository, upload `index.html`, `style.css`, `script.js`, then enable GitHub Pages from Settings → Pages → Deploy from branch.
